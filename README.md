# Python Bootcamp

A 60-day structured Python training program built toward a career transition into Operations or Business Analysis. Each session is committed daily, building a progressive portfolio from fundamentals through a capstone data pipeline project.

---

## Objective

Develop applied Python skills relevant to operations analysis: data ingestion, transformation, KPI calculation, statistical process control, and dashboard output. The capstone project (Days 56–60) mirrors real DMAIC Control Phase deliverables using manufacturing data.

---

## Skills Progression

| Phase | Days | Focus |
|---|---|---|
| Foundation | 1–20 | Variables, data types, control flow, functions, file I/O |
| Building Blocks | 21–55 | OOP, Pandas, NumPy, Matplotlib, error handling, APIs |
| Portfolio Project | 56–60 | End-to-end data pipeline and dashboard |

---

## Technologies

- **Language:** Python 3.x
- **IDE:** VS Code, Jupyter Notebook
- **Libraries:** Pandas, NumPy, Matplotlib *(introduced progressively)*
- **Version Control:** Git, GitHub
- **Methodology:** Bootcamp-style daily sessions, ~50 min each

## Capstone Project — Manufacturing OEE & Defect Analytics Dashboard

**Days 56–60**

A Python data pipeline that ingests simulated production line data, calculates OEE (Availability × Performance × Quality), identifies defect trends using control chart logic, and outputs a Pandas/Matplotlib dashboard.

Mirrors real Lean Six Sigma Control Phase (DMAIC) deliverables.

**Deliverables:**

- `oee_calculator.py` — OEE metric engine
- `defect_analysis.ipynb` — Defect trend analysis notebook
- `dashboard.py` — Summary dashboard output
- `sample_data.csv` — Simulated production dataset
- `README.md` — Project documentation
